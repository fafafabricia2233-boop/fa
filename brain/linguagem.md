# Linguagem

A linguagem é o meio pelo qual o pensamento se torna compartilhável.

## Função
- Comunicação: transferir modelos mentais entre mentes
- Cognição: a linguagem molda o que podemos pensar
- Memória: externalizar conhecimento para além do biológico

## Estrutura
- Fonemas → morfemas → palavras → frases → discurso
- Sintaxe: regras de combinação
- Semântica: significado
- Pragmática: uso em contexto

## LLMs e linguagem
Modelos de linguagem aprendem padrões estatísticos de texto.
Emergem capacidades de raciocínio, analogia e síntese não explicitamente programadas.
