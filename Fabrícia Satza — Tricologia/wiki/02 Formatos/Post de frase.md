# Post de frase

O formato mais rápido de publicar. Uma frase sua com foto de perfil, nome e
arroba. Lê rápido e **não soa propaganda, porque é uma fala e não um anúncio**.

## O padrão está fechado

| | |
|---|---|
| Nome | Fabrícia Satza \| Tricologia Capilar, com o selo |
| Texto | peso único, **sem negrito** — ver [[Tipografia e escala]] |
| Rodapé | só o arroba, **sem seta** |
| Limite | até 5 linhas |

**Sem negrito** porque fala não tem ênfase — marcar palavra ali denuncia que a
frase foi montada para convencer.

**Sem seta** porque num post avulso não há para onde arrastar. Se a citação for
usada dentro de um [[Carrossel|carrossel]], a seta volta.

**Sem imitar a interface do Twitter** ([[Decisões tomadas]])**.** Copiar a
interface de outra empresa entrega o post visualmente a ela. Foto, nome, arroba e fala já carregam o
formato sozinhos.

## Como pedir

Mande a frase. Se mandar várias de uma vez, saem todas juntas.

As frases já escritas estão em [[Publicações]]; as que ainda faltam desenvolver,
em [[Banco de ideias]].
