# Carrossel

6 a 8 slides. Existem 12 blocos prontos; escolha, apague o resto, reordene.

| Bloco | Quando |
|---|---|
| **Capa** | sempre o primeiro. Só o gancho. |
| **Quadro** | a frase que a pessoa printa |
| **Foto com caixa** | texto sobre foto qualquer |
| **Foto sem caixa** | só quando a imagem tem área limpa |
| **Lista** | até 4 itens |
| **Etapas** | quando a **ordem** importa |
| **Comparativo** | mito × fato, o que parece × o que é |
| **Ciclo** | fases em sequência |
| **Definição** | explicar um termo sem soar aula |
| **Dado** | um número só |
| **Citação** | uma fala sua |
| **Virada** | fundo de cor. **Uma por carrossel** |
| **Chamada** | sempre o último |

Etapas, comparativo, ciclo e definição são os **quadros explicativos**. Um
carrossel que ensina carrega no máximo dois; três seguidos viram apostila.

## O quadro

Duas cantoneiras em L que se cruzam, deixando dois cantos abertos. A moldura
fechada é o lugar-comum do nicho; a aberta respira e é sua.

## Escreva o texto primeiro

Fora do template. Escrever dentro do HTML empurra você a encher o slide só
porque tem espaço sobrando.
