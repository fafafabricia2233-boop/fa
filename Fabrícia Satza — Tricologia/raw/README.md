# Fontes brutas

Aqui ficam os documentos originais: artigos, papers, PDFs, transcrições,
anotações de aula, capturas de tricoscopia.

**Esta pasta é imutável.** O agente lê daqui e nunca edita nem apaga nada. Se
uma fonte precisar ser corrigida, a correção vira uma fonte nova — o histórico
do que você leu não se reescreve.

`raw/assets/` guarda as imagens. A pasta de anexos do Obsidian já aponta para
lá, então imagem colada ou baixada com o Web Clipper cai no lugar certo
sozinha.

## Como ingerir

1. Coloque o arquivo aqui.
2. Peça ao agente para processar.
3. Ele lê, conversa com você sobre o que achou, e só então escreve: um resumo
   em `wiki/06 Fontes/`, as atualizações nas páginas que a fonte toca, o
   `index.md` e o `log.md`.

O passo que faz o padrão valer é o terceiro — não é arquivar o resumo, é
integrar o que a fonte muda no resto do wiki.

## O que não entra

**Nada que identifique uma paciente.** Nem foto com rosto, nem nome, nem
prontuário, nem data que permita identificar. Imagem de paciente só existe aqui
se houver autorização escrita, e ainda assim sem identificação.
